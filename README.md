## 🛠️ Quick Commands

### Launch Application (From Repository Root)
```cmd
.\run.bat
```

### Run Frontend Build
```cmd
cd frontend
npm run build
```

### Run Python Backend Directly
```cmd
uvicorn api:app --reload --port 8000
```
